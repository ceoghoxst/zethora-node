Architecture

One chain, three layers: a fast proof-of-work base, a privacy pool that is private by default, and an execution layer that proves its work instead of trusting a sequencer.

Pillar 1 · L1 Base

Consensus & Mining

  • GHOSTDAG PoW — parallel BlockDAG consensus, forked from Kaspa's Rust node rather than reinvented.
  • 1-second blocks — a cadence fast enough to settle ZK proofs without waiting on a 12-second slot.
  • RandomZ CPU mining — a RandomX variant tuned for Zethora: ASIC-resistant and built for home machines.
  • Smooth-decay emission — the reward shrinks every block. No halving cliff, no founder allocation, 100M cap.
Pillar 2 · Privacy

Private by Default

  • Orchard Halo2 (Private by Default) — upstream Zcash Orchard 0.16.0, used unmodified. Wallets default to shielded addresses.
  • Shielded Coinbase — consensus rules let miners route block rewards straight into a shielded address, so fresh supply is never exposed.
  • Exchange Compliance Bridge — exchange-deposit unshields to a transparent address, and View Keys prove source of funds without exposing wallet history.
  • Gated today — the privacy flag is locked on testnet and mainnet until an independent cryptographic review is complete.
Pillar 3 · L2 Execution

zkEVM Layer 2

  • Native Rust zkEVM — the zethora-evm crate runs a full EVM through revm, decoupled from consensus and P2P.
  • EIP-1559 — Ethereum fee semantics, native signature recovery, batch state transitions with rollback protection.
  • SP1 ZK-Prover integration — the zethora-prover crate proves each batch inside the SP1 zkVM and commits its state root.
  • Status — execution engine and prover are built and integrated. The L1 settlement bridge is next.
