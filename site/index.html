Verify your download

Only download from the GitHub releases page linked here. Every release lists a SHA256 checksum for each file. Before running anything, open PowerShell in the folder and run Get-FileHash zethora-node.exe and Get-FileHash zethora-miner.exe. The hashes must match SHA256SUMS.txt and the hashes posted here at launch. If they don't match, delete the files and report it.
