How to start (about 10 minutes)

  1. Download Zethora-Setup from the releases page (button above, when testnet opens).
  2. If your browser warns the file is uncommon or unsafe: that is expected for a new, unsigned program. In Edge: Downloads → … → Keep → Show more → Keep anyway.
  3. Open it. If Windows shows "Windows protected your PC": More info → Run anyway.
  4. Click Next until it installs, then Finish. A Zethora icon appears on your desktop.
  5. Click START MINING. When Windows Security asks, tick Private networks and click Allow.
  6. Wait 1–2 minutes: Status turns Mining and the supply check turns green: BALANCED.
  7. Click BACK UP MY KEY and copy your key file somewhere safe.

Verify your download

Only download from the GitHub releases page linked here. Every release lists a SHA256 checksum for each file. Before running anything, open PowerShell in your Downloads folder and run Get-FileHash Zethora-Setup*. The hash must match the .sha256 file on the release page and the hash posted here at launch. If they don't match, delete the files and report it.
