# Security Policy

## Supported Versions
Currently, only the latest testnet release (v0.1.1-testnet.1) is supported with security updates.

## Reporting a Vulnerability
**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please send an email to YOUR_EMAIL_HERE (change this to your email). We will review the report and respond within 48 hours. If the vulnerability is confirmed, we will patch it and credit you in the release notes.
