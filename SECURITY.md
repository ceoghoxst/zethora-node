# Security policy

## Reporting a vulnerability

If you find a bug that could let someone create coins, spend a coin twice,
stall or split the network, steal funds, or crash nodes, **please report it
privately first**, not in a public issue.

- Use GitHub's private reporting: **Security** tab of this repository, then
  **Report a vulnerability**.
- Include what you found, how to reproduce it, and what an attacker could do.

What happens next:
1. We confirm we received it, usually within a few days.
2. We fix it and ship the fix.
3. After people have had time to update, we publish the details and credit
   you (unless you prefer to stay anonymous).

Please give us a reasonable time to fix a serious issue before publishing it.
Small bugs, typos and feature requests can go in normal issues.

## Scope

- Consensus, mining, the private pool, the node, the miner and the Windows
  miner app in this repository.
- Testnet coins are worth zero and there is no bug bounty yet. We will say so
  publicly if that changes.

## What we publish

Our open risks are public: docs/STATUS.md and docs/THREAT-MODEL.md.
